
# Student Academic Information System

## About the Project
The Student Academic Information System is a web-based application designed to manage and display student academic details in an organized manner.

## Objectives
- Store student information.
- Maintain academic records.
- Display student marks.
- Make student data easy to manage.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Add Student Details
- Enter Roll Number
- Add Course Information
- Enter Student Marks
- Display Student Records

## Project Structure

Student-Academic-Information/
|
|-- index.html
|-- README.md

## How to Run
1. Download or clone the repository.
2. Open index.html in a web browser.
3. Enter student details.
4. Click Add Student.
5. View student records.
